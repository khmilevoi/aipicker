## Ограничения проверки источника

Текущая схема сверена с официальным OpenAPI Artificial Analysis. Реальный endpoint без ключа возвращает 401. Успешная авторизованная загрузка из интернета не проверена: личный ключ пользователя не предоставлялся. Успешная пагинация проверена локальным HTTP-сервером с реальным парсером приложения.

Приложение требует собственного ключа Free API для реальных данных; демо явно синтетическое. Бесплатный источник содержит сводные индексы, а не все подробные результаты отдельных бенчмарков. Дистрибутив не содержит ключей или скачанного набора данных.
