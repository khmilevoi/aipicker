## Ограничения проверки источника

Текущая схема сверена с официальным OpenAPI Artificial Analysis. Парсер принимает актуальные `creator.name` при отсутствующем или пустом `creator.slug`; непустой `slug` остаётся авторитетным и не подменяется `name`. Реальный endpoint без ключа возвращает 401. Успешная авторизованная загрузка из интернета проверена безопасным одноразовым диагностическим запросом без сохранения или вывода ключа. Успешная пагинация проверена локальным HTTP-сервером с реальным парсером приложения.

Кнопка получения бесплатного ключа использует штатный hyperlink egui. Разрешённый Cargo feature-граф и релизная сборка подтверждают наличие native URL opening; фактический переход во внешний браузер в этой итерации не автоматизировался, получение или создание ключа не выполнялось.

Приложение требует собственного ключа Free API для реальных данных; демо явно синтетическое. Бесплатный источник содержит сводные индексы, а не все подробные результаты отдельных бенчмарков. Дистрибутив не содержит ключей или скачанного набора данных.
