# AI Picker

Нативный виджет на Rust для Windows 10/11: выбор модели по бенчмаркам и стоимости, с постоянной иконкой в системном трее.

## Запуск

Откройте `aipicker.exe` из каталога `dist/AI-Picker`. Установка Rust или браузерного движка для запуска не нужна.

В первый раз нажмите **«Подключить данные»**. В разделе **«Данные и баланс»** укажите собственный бесплатный ключ [Artificial Analysis](https://artificialanalysis.ai/data-api) и нажмите **«Применить и загрузить»**. При желании включите защищённое сохранение ключа через Windows DPAPI. Ключ не поставляется вместе с приложением.

Для знакомства без ключа в том же разделе есть **демо**. Все его значения синтетические; демо явно обозначено и не записывает данные или настройки поверх ваших рабочих.

## Использование

- Нажатие на иконку в трее открывает виджет. Если Windows спрятала иконку, она находится под стрелкой скрытых значков.
- Нажатие или перетаскивание бегунка выбирает модель. После клика шкалу можно переключать стрелками клавиатуры. Наведение на точку показывает модель.
- Иконка слева открывает фильтр: поставщики, отдельные модели и схлопывание уровней reasoning.
- Шеврон справа открывает большой вид с картой «цена / качество», графиками бенчмарков и настройками.
- Крестик или Alt+F4 скрывает окно в трей. Полное завершение — **«Выход»** в меню правой кнопки по иконке трея.
- Заголовок можно перетаскивать. Размер большого окна можно менять; компактный вид сохраняет небольшие размеры.

Компактный экран светлый: белый фон, сиреневая шкала и белый бегунок. На нём нет выбора отдельных метрик или сортировок.

## Как устроен единый баланс

Простой слайдер упорядочен по единому баллу, справа — более высокий баланс. Он учитывает все доступные показатели:

- Качество: AA Intelligence, Coding, Agentic.
- Стоимость: входные токены, выходные токены и средняя стоимость задачи AA.

Каждое значение переводится в относительный ранг среди **всего загруженного пула**. Для цены более низкое значение получает более высокий ранг. Внутри каждой группы ранги усредняются. По умолчанию качество имеет вес 65%, стоимость — 35%; вес настраивается в большом виде.

`Баланс = 100 × (вес качества × средний ранг качества + вес стоимости × средний обратный ранг цен)`

Это балл приложения, а не официальный бенчмарк и не процент правильных ответов. При совпадающих значениях используется средний ранг; единственное измеренное значение имеет нейтральный ранг. Отсутствующие данные не считаются нулями. Детали показывают полноту — например, 5 из 6 показателей. Без данных хотя бы одной группы баланс не рассчитывается. Снятие галочки с модели не меняет базу расчёта остальных моделей.

## Оптимальные уровни reasoning

Фильтр включён по умолчанию и влияет только на компактный пикер. Более дорогой вариант одной и той же версии модели скрывается, если сохранённый вариант:

- дешевле как минимум на 20% **по стоимости задачи AA**;
- уступает не более 2 баллов в каждом доступном индексе качества.

Пороги изменяются в фильтре, в разделе «Правила и скрытые варианты». Там же видно, что заменено и на что. Замены не образуют цепочек с накапливающейся потерей качества. Разные версии/поставщики не объединяются. Неизвестные форматы reasoning остаются отдельными; при отсутствии стоимости задачи сравнение не выполняется. Если у более дешёвой модели нет нужной оценки, она не может заменить измеренный вариант.

Тариф за токен может совпадать у разных уровней reasoning, поэтому он не используется вместо стоимости задачи. В большом графике остаются все модели, включённые вручную.

## Источник и ограничения данных

Используется [официальный Free API Artificial Analysis](https://artificialanalysis.ai/data-api/docs): `GET /api/v2/language/models/free`, с загрузкой всех страниц. Начальный пул — модели OpenAI и Anthropic, включая опубликованные варианты Codex/Claude. Наличие конкретной версии зависит от покрытия источника; приложение не выдумывает недостающие результаты.

Free предоставляет сводные индексы, цены токенов и стоимость задач; детальная разбивка по отдельным тестам может требовать платного тарифа. Графики приложения строятся по загруженным сводным индексам. Средняя стоимость задачи AA не является оценкой цены произвольной пользовательской задачи. Цены токенов — USD за миллион, без пользовательских скидок; смешанная цена по умолчанию использует 75% входа / 25% выхода. Ось стоимости большого графика можно переключить на задачу AA.

Обновление выполняется в фоне при устаревшем кеше и затем раз в сутки. Доступна ручная загрузка. Ограничения API и `Retry-After` соблюдаются; частые ручные запросы ограничены паузой. Весь новый набор проверяется перед заменой кеша. Ошибки сети, авторизации, формата или записи сохраняют последний корректный кеш. Подробности ошибки доступны в большом окне.

Бесплатный API требует личного ключа и атрибуции; его данные предназначены для внутреннего/личного использования. Дистрибутив не содержит ключей и загруженных данных. Условия: [Artificial Analysis Data API](https://artificialanalysis.ai/data-api).

## Где хранятся настройки

`%LOCALAPPDATA%\AI Picker`:

- `preferences.json` — выбранная модель, фильтры, параметры баланса и пауза API;
- `benchmarks.json` — последний полностью загруженный набор, время и версия индекса;
- `credential.dpapi` — зашифрованный ключ, если включено сохранение.

Ключ DPAPI привязан к учётной записи Windows. Его нельзя перенести простым копированием на другой компьютер/пользователя. Без галочки ключ живёт только в текущем процессе. Также поддерживается переменная `ARTIFICIAL_ANALYSIS_API_KEY`; она имеет приоритет при запуске. Выбранная модель носит информационный характер: приложение не меняет конфигурацию Codex или Claude и не запускает платные запросы к моделям.

## Параметры запуска и сборка

```powershell
.\aipicker.exe --demo
.\aipicker.exe --start-hidden
.\aipicker.exe --data-dir C:\path\to\separate-state

cargo test --all-targets
cargo clippy --all-targets -- -D warnings
cargo build --release --locked
```

Сборка требует Rust с поддержкой edition 2024 и MSVC build tools. Проверенная платформа — Windows x64. Для воспроизводимых версий зависимостей используется `Cargo.lock`. Интерфейс — egui/eframe, HTTP — reqwest, системный трей — tray-icon. Скрипты в `scripts/` предназначены для разработческой проверки на настоящем рабочем столе Windows.
