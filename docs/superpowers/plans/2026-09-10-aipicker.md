# AI Picker Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. User authorized autonomous execution through a finished application.

**Goal:** Deliver a working Windows Rust tray widget for model price/quality comparison.

**Architecture:** Native egui/eframe UI and tray-icon, with a blocking HTTP worker sending complete snapshots back to the UI. Pure domain functions govern selection and charts; atomic JSON cache is independent of encrypted credentials.

**Tech Stack:** Rust, eframe/egui, tray-icon, reqwest, serde, Windows DPAPI.

**Spec:** `docs/superpowers/specs/2026-09-10-aipicker-design.md`

## Global Constraints

- Entire application in Rust; target Windows.
- Use actual AA free API data with user key; demo is visibly synthetic and isolated.
- Missing values never become zero; compare only the chosen index/version.
- Close hides to tray; Exit terminates.
- Do not log, bundle or persist plaintext credentials.
